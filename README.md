# 🎬 Telegram Download Bot

بوت تليجرام لتحميل الفيديوهات والصوت من أشهر المنصات بكل سهولة.

---

## ✨ المميزات

- 📹 تحميل فيديو بجودة عالية (حتى 1080p)
- 🎵 استخراج الصوت فقط بصيغة MP3
- 🎯 واجهة أزرار سهلة الاستخدام
- 🗑️ حذف الملفات فوراً بعد الإرسال (حماية للخصوصية)
- 🌐 دعم 4 منصات مختلفة

---

## 🌐 المنصات المدعومة

| المنصة | الحالة |
|--------|--------|
| YouTube | ✅ مدعوم |
| Instagram | ✅ مدعوم |
| Facebook | ✅ مدعوم |
| TikTok | ✅ مدعوم |

---

## 📝 الأوامر المتاحة

| الأمر | الوظيفة |
|-------|---------|
| `/start` | عرض رسالة الترحيب والأزرار |
| `/video [الرابط]` | تحميل فيديو كامل |
| `/audio [الرابط]` | تحميل الصوت فقط (MP3) |
| `/help` | عرض دليل المساعدة |
